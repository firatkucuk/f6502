Write your first C64 program

C64Script

10 lines to a running C64 demo

C64Script compiles straight to 6502 machine code. No assembler, no linker, no ROM knowledge required.

rainbow.c64s 
// Cycle all 16 C64 colours on the border — your first C64Script program
program(0x0810) {
  var color: byte @zp = 0;

  loop {
    c64.border = color;
    color = color + 1;
    if (color == 16) { color = 0; }
  }
}
