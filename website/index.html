What's inside

The whole machine, faithfully emulated

Every component of the C64 is implemented from the transistor level up — as accurate as we can make it without running in silicon.

⚙️

MOS 6510 CPU

Cycle-accurate execution, all addressing modes, undocumented opcodes, and the i/o port at $00/$01.

🖥️

VIC-II Graphics

All graphics modes, 8 hardware sprites, collisions, badline DMA stalls, border opening, raster interrupts.

🔊

SID Sound

6581 and 8580 models. Three voices, ADSR envelopes (with the classic delay bug), resonant filter, ring mod, sync.

⌨️

CIA Timers & Keyboard

Two 6526 CIA chips, keyboard matrix, joystick ports, TOD clock.

🌐

Pure Browser

AudioWorklet for SID output, requestAnimationFrame loop, canvas rendering — no WASM, no native code.

📝

C64Script

A TypeScript-inspired language that compiles directly to 6502 machine code. Write C64 programs without assembly.

Get started

Running in five lines of HTML

index.html 
<canvas id="screen"></canvas>
<script src="f6502.min.js"></script>
<script>
  F6502.start({
    canvas: '#screen',
    roms: {
      kernal:  'kernal.rom',
      basic:   'basic.rom',
      chargen: 'chargen.rom',
    },
    program: 'game.prg', // optional
    audio:   true,
  });
</script>

C64Script

Write C64 programs in a language that feels like TypeScript

C64Script compiles to native 6502 machine code. No assembly required. You get typed variables, functions, loops, and direct access to every hardware register.

demo.c64s 
// Rainbow border — cycles all 16 C64 colours
program(0x0810) {
  var color: byte @zp = 0;

  loop {
    c64.border = color;
    color = color + 1;
    if (color == 16) { color = 0; }
  }
}

About this project

f6502 started as a passion project to understand how the Commodore 64 worked at the hardware level. Every chip — CPU, VIC-II, SID, CIAs — is implemented from scratch in TypeScript, guided by hardware manuals, VICE reference output, and the open-source test suite from the Commodore community.

The emulator is tested against the Klaus Dormann functional tests, VICE reference screenshots for VIC-II accuracy, and the VICE SID test programs. It is published under the Apache 2.0 licence.
