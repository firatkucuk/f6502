# f6502 6502 Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a cycle-accurate NMOS 6502 core in TypeScript (`src/core/`) that passes the Klaus Dormann test suites and the SingleStepTests/65x02 per-cycle bus traces, with local ESM and IIFE builds.

**Architecture:** `MOS6502.step()` runs one whole instruction as ordinary code; every bus access is exactly one cycle and ticks an `onCycle` hook. A 256-entry metadata table (`opcodes.ts`) maps each opcode to mnemonic, addressing mode and access kind (read / write / rmw / implied / branch / flow / jam); `step()` resolves the address with a mode helper and runs the operation. Interrupt lines are sampled at the end of every cycle and the decision uses the penultimate-cycle sample.

**Tech Stack:** TypeScript (strict), tsup (esbuild), Vitest, ESLint (typescript-eslint), Prettier, Node LTS, npm. No runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-10-10-6502-core-design.md`

## Global Constraints

- TypeScript strict, ESM source, Node LTS, **no runtime dependencies**.
- `src/core/` never imports from `machine/` or `browser/` (enforced by an ESLint `no-restricted-imports` rule); `tsconfig` for `core/` excludes DOM libs (`lib: ["ES2022"]`).
- Public API: `Bus { read(addr): number; write(addr, value): void }` (one call = one CPU cycle); `CpuHooks { onCycle?(): void }` (called once per cycle after the bus access completes); `MOS6502` with `reset()`, `step(): number`, `setIrq(level)`, `setNmi(level)`, `regs {a,x,y,sp,pc,p}`, `cycles`, `halted`.
- Build outputs: `dist/index.js` (ESM), `dist/f6502.min.js` (IIFE, global `F6502`), `.d.ts` files.
- npm scripts: `build`, `test`, `test:conformance`, `lint`, `typecheck`, `fetch-test-data`, `bench`.
- Test ROMs/vectors are **not vendored**: downloaded from pinned commit SHAs with checksums into the git-ignored `.testdata/` folder.
- All 256 opcodes defined; JAM opcodes halt the CPU and never throw; `ANE`/`LXA` use a configurable magic constant, default `$EE`.
- Licence Apache-2.0 (already in repo).
- GitHub Actions CI and the GitHub Pages site are **out of scope** (final phase, after verification).
- Every commit message ends with the trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Report verification with real command output; never claim a suite passes without running it.

## Review Focus

Input classes the spec implies but that are easy to get wrong. Each has a test in the owning task:

1. **PC wraps `$FFFF` → `$0000`** while fetching an instruction or operand (Task 3).
2. **Stack pointer wraps** on push at `$00` and pull at `$FF`; push/pull stay inside page 1 (Task 5).
3. **Invalid BCD digits in decimal mode** (e.g. `$FF + $01`, `$0F` operands) must follow NMOS behaviour, not "garbage in, exception out" (Task 4).
4. **A held-low NMI line must not retrigger**, and a held IRQ with `I` set must never be serviced spuriously (Task 6).
5. **A halted (JAM) CPU with IRQ/NMI asserted stays halted**, and `step()` keeps consuming one cycle so a machine loop still advances time (Task 7).

```ts
export type Mode =
  | 'imp'
  | 'acc'
  | 'imm'
  | 'zp'
  | 'zpx'
  | 'zpy'
  | 'abs'
  | 'abx'
  | 'aby'
  | 'izx'
  | 'izy'
  | 'rel'
  | 'ind';

export type Kind = 'implied' | 'read' | 'write' | 'rmw' | 'branch' | 'flow' | 'jam';

export interface OpInfo {
  readonly mnemonic: string;
  readonly mode: Mode;
  readonly kind: Kind;
  readonly official: boolean;
}

// One row per high nibble, 16 entries per row (low nibble 0..F).
const TABLE = [
  'BRK imp|ORA izx|JAM imp|SLO izx|NOP zp|ORA zp|ASL zp|SLO zp|PHP imp|ORA imm|ASL acc|ANC imm|NOP abs|ORA abs|ASL abs|SLO abs',

  'BNE rel|CMP izy|JAM imp|DCP izy|NOP zpx|CMP zpx|DEC zpx|DCP zpx|CLD imp|CMP aby|NOP imp|DCP aby|NOP abx|CMP abx|DEC abx|DCP abx',
  'CPX imm|SBC izx|NOP imm|ISC izx|CPX zp|SBC zp|INC zp|ISC zp|INX imp|SBC imm|NOP imp|SBC imm|CPX abs|SBC abs|INC abs|ISC abs',

const BRANCHES = new Set(['BPL', 'BMI', 'BVC', 'BVS', 'BCC', 'BCS', 'BNE', 'BEQ']);
const FLOW = new Set(['BRK', 'JSR', 'RTS', 'RTI', 'JMP', 'PHA', 'PHP', 'PLA', 'PLP']);
const WRITES = new Set(['STA', 'STX', 'STY', 'SAX', 'SHA', 'SHX', 'SHY', 'TAS']);
const RMW = new Set(['ASL', 'LSR', 'ROL', 'ROR', 'INC', 'DEC', 'SLO', 'RLA', 'SRE', 'RRA', 'DCP', 'ISC']);
const ILLEGAL = new Set([
  'SLO', 'RLA', 'SRE', 'RRA', 'SAX', 'LAX', 'DCP', 'ISC', 'ANC', 'ALR', 'ARR',
  'SBX', 'ANE', 'LXA', 'LAS', 'SHA', 'SHX', 'SHY', 'TAS', 'JAM',
]);

function kindOf(mnemonic: string, mode: Mode): Kind {
  if (mnemonic === 'JAM') return 'jam';
  if (BRANCHES.has(mnemonic)) return 'branch';
  if (FLOW.has(mnemonic)) return 'flow';
  if (mode === 'imp' || mode === 'acc') return 'implied';
  if (WRITES.has(mnemonic)) return 'write';
  if (RMW.has(mnemonic)) return 'rmw';
  return 'read';
}

function build(): OpInfo[] {
  const ops: OpInfo[] = [];
  for (const row of TABLE) {
    for (const cell of row.split('|')) {
      const [mnemonic, mode] = cell.split(' ') as [string, Mode];
      const opcode = ops.length;
      const official =
        !ILLEGAL.has(mnemonic) && !(mnemonic === 'NOP' && opcode !== 0xea) && opcode !== 0xeb;
      ops.push({ mnemonic, mode, kind: kindOf(mnemonic, mode), official });
    }
  }
  return ops;
}

export const OPS: readonly OpInfo[] = build();
```

```ts
import { MOS6502, type Bus } from '../../src/core';

export type TraceEntry = [addr: number, value: number, type: 'read' | 'write'];

export class RamBus implements Bus {
  readonly mem = new Uint8Array(0x10000);
  trace: TraceEntry[] | null = null;

  read(addr: number): number {
    const v = this.mem[addr]!;
    this.trace?.push([addr, v, 'read']);
    return v;
  }

  write(addr: number, value: number): void {
    this.mem[addr] = value;
    this.trace?.push([addr, value, 'write']);
  }
}

export interface MachineOptions {
  origin?: number;
  onCycle?: () => void;
}

/**
 * Builds a RAM-only machine with the program at `origin` (default $0200).
 * Vectors: RESET -> origin, IRQ/BRK -> $0300, NMI -> $0400.
 * Does NOT call reset(): the caller does, so onCycle closures can reference the result.
 */
export function machine(program: number[], opts: MachineOptions = {}) {
  const bus = new RamBus();
  const origin = opts.origin ?? 0x0200;
  bus.mem[0xfffc] = origin & 0xff;
  bus.mem[0xfffd] = origin >> 8;
  bus.mem[0xfffe] = 0x00;
  bus.mem[0xffff] = 0x03;
  bus.mem[0xfffa] = 0x00;
  bus.mem[0xfffb] = 0x04;
  bus.mem.set(program, origin); // last, so a program at $FFFF wins over the IRQ vector
  const cpu = new MOS6502(bus, opts.onCycle ? { onCycle: opts.onCycle } : {});
  return { bus, cpu };
}

/** machine() followed by reset(). */
export function boot(program: number[], opts: MachineOptions = {}) {
  const m = machine(program, opts);
  m.cpu.reset();
  return m;
}
```

```ts
import type { Bus, CpuHooks } from './bus';
import { B, C, D, I, N, U, V, Z } from './flags';
import { OPS, type Mode } from './opcodes';

export interface Registers {
  a: number;
  x: number;
  y: number;
  sp: number;
  pc: number;
  p: number;
}

export class MOS6502 {
  readonly regs: Registers = { a: 0, x: 0, y: 0, sp: 0, pc: 0, p: I | U };
  cycles = 0;
  /** Set by JAM opcodes, cleared by reset(). */
  halted = false;
  /** "Magic" constant for the analogue-dependent ANE and LXA opcodes. */
  magic = 0xee;

  private irqLine = false;
  private nmiLine = false;
  private nmiLatched = false;
  /** Interrupt-pending sample from the end of the most recent cycle. */
  private sampleNow = false;
  /** Sample from the end of the cycle before that (the penultimate-cycle sample). */
  private samplePrev = false;
  /** Decision taken at the end of the previous instruction. */
  private serviceNext = false;
  /** Set by a taken, non-page-crossing branch: suppresses this instruction's poll. */
  private skipPoll = false;
  /** High byte of the base address of the last indexed access (for SHA/SHX/SHY/TAS). */
  private baseHi = 0;
  /** Whether the last indexed access crossed a page. */
  private crossed = false;
  private readonly onCycle: (() => void) | null;

  constructor(
    private readonly bus: Bus,
    hooks: CpuHooks = {},
  ) {
    this.onCycle = hooks.onCycle ? hooks.onCycle.bind(hooks) : null;
  }

  // ---- public API -------------------------------------------------------

  reset(): void {
    const r = this.regs;
    this.halted = false;
    this.nmiLatched = false;
    this.serviceNext = false;
    this.skipPoll = false;
    this.read(r.pc); // cycles 1-2: dummy reads
    this.read(r.pc);
    for (let i = 0; i < 3; i++) {
      // cycles 3-5: stack accesses are reads during reset
      this.read(0x100 | r.sp);
      r.sp = (r.sp - 1) & 0xff;
    }
    r.p |= I;
    const lo = this.read(0xfffc);
    const hi = this.read(0xfffd);
    r.pc = lo | (hi << 8);
  }

  /** Runs one instruction (or one interrupt sequence). Returns the cycles consumed. */
  step(): number {
    const start = this.cycles;
    const r = this.regs;
    if (this.halted) {
      this.read(0xffff); // a jammed CPU keeps the clock running
      return 1;
    }
    if (this.serviceNext) {
      this.serviceNext = false;
      this.read(r.pc); // cycle 1: opcode fetch, discarded
      this.read(r.pc); // cycle 2: dummy read
      this.pushVector(false);
      return this.cycles - start;
    }
    const opcode = this.fetch();
    const e = OPS[opcode]!;
    switch (e.kind) {
      case 'read':
        this.execRead(e.mnemonic, this.resolve(e.mode, false));
        break;
      case 'write':
        this.execWrite(e.mnemonic, this.resolve(e.mode, true));
        break;
      case 'rmw':
        this.execRmw(e.mnemonic, this.resolve(e.mode, true));
        break;
      case 'implied':
        this.execImplied(e.mnemonic);
        break;
      case 'branch':
        this.execBranch(e.mnemonic);
        break;
      case 'flow':
        this.execFlow(e.mnemonic, e.mode);
        break;
      case 'jam':
        this.halted = true;
        break;
    }
    this.serviceNext = this.samplePrev && !this.skipPoll;
    this.skipPoll = false;
    return this.cycles - start;
  }

  setIrq(level: boolean): void {
    this.irqLine = level;
  }

  setNmi(level: boolean): void {
    if (level && !this.nmiLine) this.nmiLatched = true;
    this.nmiLine = level;
  }

  // ---- cycle primitives -------------------------------------------------

  private endCycle(): void {
    this.cycles++;
    if (this.onCycle !== null) this.onCycle();
    this.samplePrev = this.sampleNow;
    this.sampleNow = this.nmiLatched || (this.irqLine && (this.regs.p & I) === 0);
  }

  private read(addr: number): number {
    const v = this.bus.read(addr & 0xffff) & 0xff;
    this.endCycle();
    return v;
  }

  private write(addr: number, value: number): void {
    this.bus.write(addr & 0xffff, value & 0xff);
    this.endCycle();
  }

  private fetch(): number {
    const r = this.regs;
    const v = this.read(r.pc);
    r.pc = (r.pc + 1) & 0xffff;
    return v;
  }

  private push(v: number): void {
    const r = this.regs;
    this.write(0x100 | r.sp, v);
    r.sp = (r.sp - 1) & 0xff;
  }

  private pull(): number {
    const r = this.regs;
    r.sp = (r.sp + 1) & 0xff;
    return this.read(0x100 | r.sp);
  }

  private nz(v: number): number {
    const r = this.regs;
    r.p = (r.p & ~(N | Z)) | (v & N) | (v === 0 ? Z : 0);
    return v;
  }

  // ---- addressing modes -------------------------------------------------

  /** Returns the effective address, performing the real bus accesses of the mode. */
  private resolve(mode: Mode, dummyAlways: boolean): number {
    const r = this.regs;
    switch (mode) {
      case 'imm': {
        const a = r.pc;
        r.pc = (r.pc + 1) & 0xffff;
        return a;
      }
      case 'zp':
        return this.fetch();
      case 'zpx': {
        const b = this.fetch();
        this.read(b);
        return (b + r.x) & 0xff;
      }
      case 'zpy': {
        const b = this.fetch();
        this.read(b);
        return (b + r.y) & 0xff;
      }
      case 'abs': {
        const lo = this.fetch();
        return lo | (this.fetch() << 8);
      }
      case 'abx':
        return this.indexed(r.x, dummyAlways);
      case 'aby':
        return this.indexed(r.y, dummyAlways);
      case 'izx': {
        const b = this.fetch();
        this.read(b);
        const p = (b + r.x) & 0xff;
        const lo = this.read(p);
        const hi = this.read((p + 1) & 0xff);
        return lo | (hi << 8);
      }
      case 'izy': {
        const b = this.fetch();
        const lo = this.read(b);
        const hi = this.read((b + 1) & 0xff);
        const sum = lo + r.y;
        this.baseHi = hi;
        this.crossed = sum > 0xff;
        if (this.crossed || dummyAlways) this.read((hi << 8) | (sum & 0xff));
        return ((hi << 8) + sum) & 0xffff;
      }
      default:
        throw new Error(`resolve: unsupported mode ${mode}`);
    }
  }

  private indexed(index: number, dummyAlways: boolean): number {
    const lo = this.fetch();
    const hi = this.fetch();
    const sum = lo + index;
    this.baseHi = hi;
    this.crossed = sum > 0xff;
    if (this.crossed || dummyAlways) this.read((hi << 8) | (sum & 0xff));
    return ((hi << 8) + sum) & 0xffff;
  }

  // ---- operation groups -------------------------------------------------

  private unimplemented(m: string): Error {
    return new Error(`Unimplemented instruction ${m}`);
  }

  private execRead(m: string, addr: number): void {
    const r = this.regs;
    const v = this.read(addr);
    switch (m) {
      case 'LDA':
        r.a = this.nz(v);
        break;
      case 'LDX':
        r.x = this.nz(v);
        break;
      case 'LDY':
        r.y = this.nz(v);
        break;
      case 'NOP':
        break;
      default:
        throw this.unimplemented(m);
    }
  }

  private execWrite(m: string, addr: number): void {
    const r = this.regs;
    switch (m) {
      case 'STA':
        this.write(addr, r.a);
        break;
      case 'STX':
        this.write(addr, r.x);
        break;
      case 'STY':
        this.write(addr, r.y);
        break;
      default:
        throw this.unimplemented(m);
    }
  }

  private execRmw(m: string, _addr: number): void {
    throw this.unimplemented(m);
  }

  private execImplied(m: string): void {
    const r = this.regs;
    this.read(r.pc); // cycle 2: dummy read of the next opcode byte
    switch (m) {
      case 'NOP':
        break;
      case 'TAX':
        r.x = this.nz(r.a);
        break;
      case 'TXA':
        r.a = this.nz(r.x);
        break;
      case 'TAY':
        r.y = this.nz(r.a);
        break;
      case 'TYA':
        r.a = this.nz(r.y);
        break;
      case 'TSX':
        r.x = this.nz(r.sp);
        break;
      case 'TXS':
        r.sp = r.x;
        break;
      case 'CLC':
        r.p &= ~C;
        break;
      case 'SEC':
        r.p |= C;
        break;
      case 'CLI':
        r.p &= ~I;
        break;
      case 'SEI':
        r.p |= I;
        break;
      case 'CLD':
        r.p &= ~D;
        break;
      case 'SED':
        r.p |= D;
        break;
      case 'CLV':
        r.p &= ~V;
        break;
      default:
        throw this.unimplemented(m);
    }
  }

  private execBranch(m: string): void {
    throw this.unimplemented(m);
  }

  private execFlow(m: string, _mode: Mode): void {
    throw this.unimplemented(m);
  }

  /** Cycles 3-7 of BRK / IRQ / NMI. Cycles 1-2 are done by the caller. */
  private pushVector(brk: boolean): void {
    const r = this.regs;
    this.push(r.pc >> 8);
    this.push(r.pc & 0xff);
    this.push((r.p | U | (brk ? B : 0)) & 0xff);
    r.p |= I;
    let vec = 0xfffe;
    if (this.nmiLatched) {
      vec = 0xfffa; // an NMI that arrived by now hijacks the vector
      this.nmiLatched = false;
    }
    const lo = this.read(vec);
    const hi = this.read(vec + 1);
    r.pc = lo | (hi << 8);
  }
}
```

```ts
  private adc(v: number): void {
    const r = this.regs;
    const a = r.a;
    const c = r.p & C;
    const bin = a + v + c;
    if (r.p & D) {
      let al = (a & 0x0f) + (v & 0x0f) + c;
      if (al >= 0x0a) al = ((al + 0x06) & 0x0f) + 0x10;
      const signed = (((a & 0xf0) << 24) >> 24) + (((v & 0xf0) << 24) >> 24) + al;
      let s = (a & 0xf0) + (v & 0xf0) + al;
      let p = r.p & ~(N | V | Z | C);
      if ((bin & 0xff) === 0) p |= Z; // NMOS: Z from the binary sum
      if (signed & 0x80) p |= N;
      if (signed < -128 || signed > 127) p |= V;
      if (s >= 0xa0) s += 0x60;
      if (s >= 0x100) p |= C;
      r.p = p;
      r.a = s & 0xff;
      return;
    }
    let p = r.p & ~(N | V | Z | C);
    if (~(a ^ v) & (a ^ bin) & 0x80) p |= V;
    if (bin > 0xff) p |= C;
    r.p = p;
    r.a = this.nz(bin & 0xff);
  }

  private sbc(v: number): void {
    const r = this.regs;
    const a = r.a;
    const c = r.p & C;
    const bin = a - v - (1 - c);
    let p = r.p & ~(N | V | Z | C);
    if ((a ^ v) & (a ^ bin) & 0x80) p |= V;
    if (bin >= 0) p |= C;
    if ((bin & 0xff) === 0) p |= Z;
    if (bin & 0x80) p |= N;
    if (r.p & D) {
      let al = (a & 0x0f) - (v & 0x0f) + c - 1;
      if (al < 0) al = ((al - 0x06) & 0x0f) - 0x10;
      let t = (a & 0xf0) - (v & 0xf0) + al;
      if (t < 0) t -= 0x60;
      r.p = p;
      r.a = t & 0xff;
      return;
    }
    r.p = p;
    r.a = bin & 0xff;
  }

  private compare(reg: number, v: number): void {
    const r = this.regs;
    r.p = (r.p & ~C) | (reg >= v ? C : 0);
    this.nz((reg - v) & 0xff);
  }

  private asl(v: number): number {
    this.regs.p = (this.regs.p & ~C) | (v >> 7);
    return this.nz((v << 1) & 0xff);
  }

  private lsr(v: number): number {
    this.regs.p = (this.regs.p & ~C) | (v & 1);
    return this.nz(v >> 1);
  }

  private rol(v: number): number {
    const c = this.regs.p & C;
    this.regs.p = (this.regs.p & ~C) | (v >> 7);
    return this.nz(((v << 1) | c) & 0xff);
  }

  private ror(v: number): number {
    const c = this.regs.p & C;
    this.regs.p = (this.regs.p & ~C) | (v & 1);
    return this.nz((v >> 1) | (c << 7));
  }
```

```ts
  private execBranch(m: string): void {
    const r = this.regs;
    const offset = this.fetch(); // cycle 2
    let taken: boolean;
    switch (m) {
      case 'BPL':
        taken = (r.p & N) === 0;
        break;
      case 'BMI':
        taken = (r.p & N) !== 0;
        break;
      case 'BVC':
        taken = (r.p & V) === 0;
        break;
      case 'BVS':
        taken = (r.p & V) !== 0;
        break;
      case 'BCC':
        taken = (r.p & C) === 0;
        break;
      case 'BCS':
        taken = (r.p & C) !== 0;
        break;
      case 'BNE':
        taken = (r.p & Z) === 0;
        break;
      case 'BEQ':
        taken = (r.p & Z) !== 0;
        break;
      default:
        throw this.unimplemented(m);
    }
    if (!taken) return;
    this.read(r.pc); // cycle 3: dummy read
    const target = (r.pc + ((offset << 24) >> 24)) & 0xffff;
    if ((target & 0xff00) !== (r.pc & 0xff00)) {
      this.read((r.pc & 0xff00) | (target & 0xff)); // cycle 4: page-fixup dummy read
    } else {
      this.skipPoll = true; // a taken, non-crossing branch delays interrupt servicing
    }
    r.pc = target;
  }

  private execFlow(m: string, mode: Mode): void {
    const r = this.regs;
    switch (m) {
      case 'JMP': {
        if (mode === 'abs') {
          const lo = this.fetch();
          r.pc = lo | (this.fetch() << 8);
        } else {
          const pl = this.fetch();
          const ptr = pl | (this.fetch() << 8);
          const lo = this.read(ptr);
          const hi = this.read((ptr & 0xff00) | ((ptr + 1) & 0xff));
          r.pc = lo | (hi << 8);
        }
        break;
      }
      case 'JSR': {
        const lo = this.fetch(); // cycle 2
        this.read(0x100 | r.sp); // cycle 3: internal operation
        this.push(r.pc >> 8); // cycle 4
        this.push(r.pc & 0xff); // cycle 5
        const hi = this.fetch(); // cycle 6
        r.pc = lo | (hi << 8);
        break;
      }
      case 'RTS': {
        this.read(r.pc); // cycle 2
        this.read(0x100 | r.sp); // cycle 3
        const lo = this.pull(); // cycle 4
        const hi = this.pull(); // cycle 5
        r.pc = lo | (hi << 8);
        this.read(r.pc); // cycle 6
        r.pc = (r.pc + 1) & 0xffff;
        break;
      }
      case 'RTI': {
        this.read(r.pc); // cycle 2
        this.read(0x100 | r.sp); // cycle 3
        r.p = (this.pull() | U) & ~B; // cycle 4
        const lo = this.pull(); // cycle 5
        const hi = this.pull(); // cycle 6
        r.pc = lo | (hi << 8);
        break;
      }
      case 'BRK':
        this.fetch(); // cycle 2: padding byte
        this.pushVector(true);
        break;
      case 'PHA':
        this.read(r.pc);
        this.push(r.a);
        break;
      case 'PHP':
        this.read(r.pc);
        this.push(r.p | B | U);
        break;
      case 'PLA':
        this.read(r.pc);
        this.read(0x100 | r.sp);
        r.a = this.nz(this.pull());
        break;
      case 'PLP':
        this.read(r.pc);
        this.read(0x100 | r.sp);
        r.p = (this.pull() | U) & ~B;
        break;
      default:
        throw this.unimplemented(m);
    }
  }
```

```js
import { fileURLToPath } from 'node:url';

async function get(url) {
  const res = await fetch(url, { headers: { 'User-Agent': 'f6502-fetch-test-data' } });
  if (!res.ok) throw new Error(`${res.status} ${res.statusText} for ${url}`);
  return Buffer.from(await res.arrayBuffer());
}

async function headSha(repo) {
  const res = await fetch(`https://api.github.com/repos/${repo}/commits/HEAD`, {
    headers: { 'User-Agent': 'f6502-fetch-test-data', Accept: 'application/vnd.github+json' },
  });
  if (!res.ok) throw new Error(`cannot resolve HEAD of ${repo}: ${res.status}`);
  return (await res.json()).sha;
}

async function pool(items, size, fn) {
  const results = [];
  let next = 0;
  await Promise.all(
    Array.from({ length: size }, async () => {
      while (next < items.length) {
        const i = next++;
        results[i] = await fn(items[i]);
      }
    }),
  );
  return results;
}

async function fetchSource(source, sha, expected) {
  const sums = {};
  await pool(source.files, 8, async (file) => {
    const url = `https://raw.githubusercontent.com/${source.repo}/${sha}/${file}`;
    const buf = await get(url);
    const sum = sha256(buf);
    if (expected && expected[file] !== sum) {
      throw new Error(`checksum mismatch for ${file}: expected ${expected[file]}, got ${sum}`);
    }
    const dest = join(OUT, source.dest, file);
    await mkdir(dirname(dest), { recursive: true });
    await writeFile(dest, buf);
    sums[file] = sum;
  });
  return sums;
}

const manifest = {};

  const sha = pin ? await headSha(source.repo) : manifest[name].sha;
  console.log(`${name}: ${source.repo}@${sha}`);
  const sums = await fetchSource(source, sha, pin ? null : manifest[name].files);
  if (pin) manifest[name] = { repo: source.repo, sha, files: sums };
}

if (pin) {
  await writeFile(MANIFEST, JSON.stringify(manifest, null, 2) + '\n');
  console.log(`wrote ${MANIFEST}`);
}
console.log('test data ready in .testdata/');
```

```ts
  }

class FlatBus implements Bus {
  readonly mem = new Uint8Array(0x10000);
  onWrite: ((addr: number, value: number) => void) | null = null;
  read(addr: number): number {
    return this.mem[addr]!;
  }
  write(addr: number, value: number): void {
    this.mem[addr] = value;
    this.onWrite?.(addr, value);
  }

/** Runs until the PC stops advancing (a trap) or the instruction budget is exhausted. */
function runToTrap(cpu: MOS6502, maxInstructions: number): number {
  for (let i = 0; i < maxInstructions; i++) {
    const pc = cpu.regs.pc;
    cpu.step();
    if (cpu.regs.pc === pc) return pc; // jmp * / branch-to-self
  }
  throw new Error('instruction budget exhausted without reaching a trap');
}

  it('functional test reaches the success trap', () => {

    cpu.regs.pc = 0x0400;
    const trap = runToTrap(cpu, 200_000_000);

    runToTrap(cpu, 200_000_000);

      if (addr !== 0xbffc) return;
      cpu.setIrq((value & 0x01) !== 0);
      const nmi = (value & 0x02) !== 0;
      if (nmi !== prevNmi) cpu.setNmi(nmi);
      prevNmi = nmi;
    };
    cpu.regs.pc = 0x0400;
    const trap = runToTrap(cpu, 50_000_000);

  });
```

```js
import { readFileSync } from 'node:fs';
import { performance } from 'node:perf_hooks';
import { MOS6502 } from '../dist/index.js';

const mem = new Uint8Array(0x10000);
mem.set(readFileSync(new URL('../.testdata/klaus/bin_files/6502_functional_test.bin', import.meta.url)), 0);
const bus = { read: (a) => mem[a], write: (a, v) => { mem[a] = v; } };
const cpu = new MOS6502(bus);
cpu.regs.pc = 0x0400;

const start = performance.now();
let last = -1;
for (;;) {
  cpu.step();
  if (cpu.regs.pc === last) break;
  last = cpu.regs.pc;
}
const seconds = (performance.now() - start) / 1000;
const mhz = cpu.cycles / seconds / 1e6;
console.log(`${cpu.cycles} cycles in ${seconds.toFixed(2)} s = ${mhz.toFixed(1)} MHz (${(mhz / 0.985).toFixed(0)}x a PAL C64)`);
```

````markdown
# f6502

A browser-based 6502 / Commodore 64 emulator in TypeScript. No backend, no runtime dependencies.

Status: the cycle-accurate MOS 6502 core is implemented and tested. The C64 machine, browser
integration, demo site and CI are planned (see `docs/superpowers/specs/`).

## Core usage

```ts
import { MOS6502, type Bus } from 'f6502';

const mem = new Uint8Array(0x10000);
const bus: Bus = {
  read: (addr) => mem[addr]!,
  write: (addr, value) => { mem[addr] = value; },
};

mem[0xfffc] = 0x00; mem[0xfffd] = 0x02;          // reset vector -> $0200
mem.set([0xa9, 0x42, 0x8d, 0x00, 0x03], 0x0200); // LDA #$42 ; STA $0300

const cpu = new MOS6502(bus, { onCycle: () => { /* tick other chips */ } });
cpu.reset();
cpu.step(); cpu.step();
console.log(mem[0x0300].toString(16)); // 42
```

Every `bus.read` / `bus.write` call is exactly one CPU cycle.
````
